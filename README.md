# SourceLens AI Research Agent

Interactive React portfolio case study for an evidence-first AI research agent.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. In Vercel, select **Add New > Project**.
3. Import the repository.
4. Framework preset: **Vite**.
5. Build command: `npm run build`.
6. Output directory: `dist`.
7. Deploy.

## Before sending to interviewers

- Replace `your-email@example.com` in `src/App.jsx`.
- Replace illustrative research and evaluation figures with validated results, or keep the demonstration labels.
- Test the deployed URL in an incognito window and on mobile.

## Project structure

- `src/App.jsx`: page content and interactions
- `src/styles.css`: responsive visual design
- `src/main.jsx`: React entry point
- `index.html`: page metadata
